# 📚 Lore Organizer - APPescritores

App utilitário para PC e celular que ajuda escritores a organizar a lore de seus livros: fichas de personagens, rascunhos e linha do tempo. Tudo offline.

> Um dos meus 2 apps publicados na Microsoft Store.

### 📱 Usar agora
- 🪟 [Baixar na Microsoft Store](https://apps.microsoft.com/detail/9NHB5JM9983P?hl=pt-br&gl=BR)
- 🌐 [Usar no navegador (PWA)](https://intox583-boop.github.io/APPescritores/)

### ✨ O que ele faz
- Fichas de personagens organizadas
- Rascunhos com salvamento local
- Linha do tempo da história
- Interface leve e rápida
- Funciona 100% offline - seus textos não vão pra nuvem

### 🛠️ Como foi feito (o que eu posso fazer pra sua empresa)
- HTML, CSS, JavaScript Vanilla
- PWA instalável offline (manifest + service worker)
- Armazenamento local - privacidade total
- Publicado e aprovado na Microsoft Store
- Código aberto e adaptável: posso transformar esse molde em app para advogado, loja, clínica, etc.
